Микрофон и мишка for Windows 10/11

Right-click apply.ps1 -> Run with PowerShell (current user only, no admin).
It sets dark mode, the #ff6600 accent on title bars and borders, the wallpaper
and the orange pointers, then restarts Explorer.

To go back: Settings -> Personalization -> Themes, pick Windows (dark), and
Mouse settings -> Additional mouse settings -> Pointers -> Windows Default.
